# Module 2 Analysis – Navigation and Data Flow

## Techniques Learned
I learned how to use Navigation Compose to move between different screens in an Android app.

## How Navigation Was Implemented
I used `NavController` and `NavHost` to navigate from the student form screen to the student details screen.

## Data Passing Between Screens
The student name and ID were stored in state variables and displayed on the second screen.

## Back Navigation
I used `popBackStack()` to return to the previous screen.

## Strengths
Navigation Compose made screen navigation simple and easy to manage.

## Limitations
At first, understanding `NavController` and screen routes was a little confusing.

## Technical Decision
I used Navigation Compose because the app was built with Jetpack Compose.

## Problems I Faced
I faced some difficulty with the navigation dependency and Gradle setup.

## How I Solved Them
I corrected the dependency version and synced the Gradle project again.
